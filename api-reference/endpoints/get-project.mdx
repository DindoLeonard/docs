## Request

```bash
curl https://api.example.com/v1/projects/proj_123 \
  -H "Authorization: Bearer YOUR_API_KEY"
```

## Response

```json
{
  "id": "proj_123",
  "name": "Example project",
  "created_at": "2026-01-15T09:30:00Z"
}
```

## Parameters

| Name | In | Type | Description |
| --- | --- | --- | --- |
| `id` | path | string | The project ID, prefixed with `proj_` |
